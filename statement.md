# Project Statement

## Problem Statement
Campus event registration can become difficult when student and event information is maintained manually. Duplicate registrations, capacity problems and difficulty finding events can occur.

## Scope
CampusHub provides a small console-based system for student management, event management, registration, searching and reporting.

## Target Users
Campus coordinators and event organizers.

## High-Level Features
- Student management
- Event management
- Student registration
- Event search
- Registration reports
- Activity logging
